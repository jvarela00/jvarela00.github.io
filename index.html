BeatFlow

A private, self-hosted tool that music producer vare (prodvare) uses to publish the producer's own instrumental music.

What it does

  • Prepares videos for the producer's own beats (a static cover image with the instrumental).
  • Uploads those videos to the producer's own YouTube channels, sets their thumbnails and schedules their publication, using the YouTube Data API.
  • Reads the producer's own channel statistics (YouTube Analytics API) to understand which releases perform best.

Who can use it

BeatFlow runs only on the producer's personal computer and is used exclusively to manage channels owned by the producer. It is not offered to the public, has no user accounts and is not a hosted service.

BeatFlow uses YouTube API Services. See the Privacy Policy, the YouTube Terms of Service and the Google Privacy Policy.
