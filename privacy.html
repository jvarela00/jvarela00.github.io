Privacy Policy

Effective date: November 8, 2026

BeatFlow is a personal, self-hosted application operated by the music producer vare (prodvare, contact@prodvare.com). It runs only on the producer's own computer and is used only to manage YouTube channels that the producer owns. This policy explains what data BeatFlow accesses and how it is handled.

1. YouTube API Services

BeatFlow uses YouTube API Services. By using BeatFlow you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

2. Data accessed

When the channel owner authorizes BeatFlow with Google OAuth, BeatFlow may access:

  • Upload permission (youtube.upload): to upload the owner's own videos, set their thumbnails, titles, descriptions, tags and scheduled publication date.
  • Read-only channel data (youtube.readonly): the owner's channel and video information, to confirm uploads and avoid duplicates.
  • Read-only analytics (yt-analytics.readonly): aggregated statistics of the owner's channels (views, watch time, click-through rate, subscribers).

BeatFlow does not access data of any other YouTube user. It may also read publicly available information about other channels' public videos (titles, view counts, upload dates) for the owner's market research, as permitted by the YouTube API Services Terms.

3. How data is used and stored

  • Data is used only to provide the features above to the channel owner.
  • OAuth tokens and all retrieved data are stored locally on the owner's computer. BeatFlow has no servers and no database outside that computer.
  • Data is never sold, rented or used for advertising.
  • Statistics obtained from the YouTube API are refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies.

4. Sharing with third parties

BeatFlow does not share YouTube user data with third parties, with one exception: to generate video titles and performance suggestions, BeatFlow sends the producer's own cover images, beat information and aggregated statistics of the producer's own channels to the Anthropic API (Claude). This processing is done on the producer's behalf and is governed by Anthropic's Privacy Policy.

5. Google API Services User Data Policy

BeatFlow's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking access and deleting data

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. Revoking access stops BeatFlow from accessing the account. Locally stored data can be deleted by removing BeatFlow's data folder; deletion requests can also be sent to the contact address below and are completed within 7 days.

7. Cookies

BeatFlow does not use cookies or tracking technologies. This website does not use cookies.

8. Changes

Changes to this policy will be published on this page with a new effective date.
